# Enterprise Support

EdgeSafe Vision is open source under Apache-2.0.

Organizations sometimes need help beyond the public reference implementation. Private support can be discussed for:

- deployment assessment
- Windows / Ubuntu deployment
- camera and stream integration
- private system integration
- operational hardening
- acceptance testing
- troubleshooting and maintenance

Private customer code, credentials, production configuration and security-sensitive infrastructure are not published in this repository.

For enterprise support inquiries, contact the maintainer through GitHub.
