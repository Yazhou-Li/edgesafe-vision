# Community Outreach Guide

## Goal

Grow a responsible open-source community around practical edge-AI delivery engineering.

## Audience

- edge AI developers
- computer vision engineers
- FDE / solution engineers
- system integrators
- engineers working with cameras, events, and AI operations

## Suggested introduction

> EdgeSafe Vision is an open-source toolkit focused on the engineering gap between an AI demo and a reliable deployment workflow: events, rules, alarms, diagnostics, and acceptance evidence.
>
> We welcome feedback and reusable engineering contributions from people working on real edge-AI systems.

## Contribution rules

Welcome:

- tests
- documentation
- synthetic examples
- adapters
- diagnostics improvements
- reproducible bug reports

Avoid:

- customer data
- private network information
- credentials
- production configurations
- unsupported safety claims

## Review principles

Every contribution should be:

- small and reviewable;
- backed by tests or clear evidence;
- explicit about what it proves and does not prove;
- aligned with deployment reliability rather than demo-only features.
