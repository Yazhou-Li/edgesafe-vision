# Code of Conduct

EdgeSafe Vision welcomes technical discussion, bug reports, documentation improvements and code contributions from people of different backgrounds and experience levels.

Please:

- discuss ideas and technical disagreements respectfully;
- focus criticism on code, evidence and reproducible behavior;
- avoid publishing credentials, customer data or private deployment information;
- do not use issues or pull requests for harassment, spam or unrelated promotion;
- disclose security-sensitive findings privately rather than posting exploit-ready secrets.

Maintainers may edit, close or remove content that puts users, contributors or customer data at risk.

The goal is a practical engineering community where useful work can be reviewed, reproduced and improved.
