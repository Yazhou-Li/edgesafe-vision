# Third-Party Notices

EdgeSafe Vision is designed to integrate with open-source components.

Public code must preserve the original license obligations of any third-party source that is copied or modified.

Expected integrations may include:

- Frigate — consult the upstream repository for its current license and notices.
- OpenVINO — consult the upstream repository for its current license and notices.
- FFmpeg — licensing depends on the build and linked components.
- MQTT libraries — license depends on the selected client library.

This file should be updated whenever third-party code is added to the repository.

Do not copy third-party source into this repository until its license compatibility has been reviewed.
