# Support

## Community

Bug fixes, documentation improvements and new reference integrations are welcome through pull requests.

When sharing logs or examples, remove credentials, personal data and private deployment details.

## Deployment and integration

Organizations that need help applying EdgeSafe Vision in a real environment can contact the maintainer for:

- deployment assessment;
- Windows / Ubuntu deployment;
- camera and stream integration;
- private system integration;
- operational hardening;
- acceptance testing;
- troubleshooting and maintenance.

Support arrangements are separate from the Apache-2.0 license of the open-source project.
