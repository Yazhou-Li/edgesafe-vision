# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities or sensitive data in a public issue.

When reporting a security concern:

- remove credentials, tokens and private keys;
- remove personal or customer-identifying information;
- replace private network details with safe example values;
- include the minimum logs or reproduction details needed to understand the issue.

For ordinary bugs that do not contain sensitive information, please use GitHub Issues when available.

## Safe examples

Use documentation-only addresses and obvious placeholders in examples, for example:

```text
CAMERA_HOST=192.0.2.10
CAMERA_USER=demo
CAMERA_PASSWORD=REDACTED
```

Contributors are responsible for ensuring that material submitted to the project can be shared publicly.
